# aips-chronon Disaster Recovery

This page describes the disaster recovery solution for the aips-chronon service as well as describing the procedure(s) required for restoring service in the event of a disaster. This information greatly assists folks in Prod Support and Site Reliability Engineers in their work, but also has utility for service maintainers.
