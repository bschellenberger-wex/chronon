# aips-chronon Runbook

This runbook describes common procedures associated with operating the aips-chronon service. Procedures will typically be related to diagnosing service health and remediating issues, but may extend to cover other operational activities.

> INSTRUCTIONS (REMOVE BEFORE COMMITTING)
>
> It is recommended that runbook documentation exist in your repository alongside your codebase, but not required. Not only does documentation that lives alongside code have the greatest chance of being maintained, but also it is much more accessible because OpsLevel surfaces Markdown files in it's UI.
>
> You may link to content in Confluence or Google Docs instead if that works better for you.
>
> When documenting issue diagnosis procedures, please clearly differentiate issue description, diagnosis steps and remediation steps.
